# Sources
Toutes les sources sont listées dans `data/feeds.yaml` (articles) et `data/agenda.yaml` (événements).
Elles sont lues avec respect de `robots.txt`, 1 s entre deux requêtes, sans contournement de paywall.
Seuls titre, chapô (400 caractères max), date et lien sont stockés ; le texte complet reste chez l'éditeur.

**Statut : URLs non testées au moment de l'écriture (réseau bloqué dans l'environnement de création).**
Mets à jour ce fichier avec les flux morts remplacés (page Système).
